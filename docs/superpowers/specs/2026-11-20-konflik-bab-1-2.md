# Konflik Bab I/II dengan Bab III baru — SELESAI

Keputusan Abdi (2026-11-20): seluruh Bab I–III diselaraskan dengan teknik baru, termasuk
tinjauan pustaka. Semua butir pada daftar sebelumnya sudah dikerjakan:

- Bab I: sampel purposive 8 restoran dari 18 kandidat, target min(tersedia, 625), 500 ulasan
  berlabel, penyajian API + web, Tabel 1.2 (L1, L3, L4, L6–L8, L13), sistematika bab.
- Bab II: subbab baru purposive sampling, arsitektur klien-server dan API REST (OpenAPI, SPA),
  metrik Macro-F1 dan validasi silang, uji hipotesis (uji-t, Wilcoxon, tau Kendall, perumusan
  hipotesis); pengujian diperluas (API, peramban, keterlacakan).

Catatan sitasi: subbab baru yang bersifat teknis (REST/OpenAPI, purposive sampling, uji-t,
Wilcoxon, Kendall, Macro-F1) tidak diberi sitasi karena belum ada sumbernya di folder REFERENSI.
Tambahkan sumber dari folder REFERENSI bila dosen meminta; kunci baru ditambah di
`scripts/proposal/pustaka.py`.
