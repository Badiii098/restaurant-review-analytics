# Arsip: antarmuka Streamlit (iterasi prototipe 1)

Antarmuka ini dipakai pada iterasi pertama prototipe. Sejak arsitektur web modern
(API FastAPI + klien React, `src/rra/api`, `frontend/`) ia dipensiunkan supaya
hanya ada satu antarmuka yang harus dijaga angkanya.

Berkas disimpan untuk keterlacakan riwayat; tidak dijalankan oleh CI.
Tokens warna di `theme.py` menjadi dasar `frontend/src/styles/tokens.css`.
